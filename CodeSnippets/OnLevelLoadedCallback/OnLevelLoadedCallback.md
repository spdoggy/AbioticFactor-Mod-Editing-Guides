
# On Level Loaded Callback

- Class: Level Manager Subsystem

## Usage

Create a custom event in the DT_ClassManager (based on the Leyak actorComponent class) 
that will run automatically on game startup once the level loads.

How to Guide: https://mod.io/g/abiotic-factor/r/spawning-logic-blueprints
