# Wait for a Get result to be valid

- Class: Any variable
- Submitter: astro_age

## Usage

Wait for a variable to be valid before continuing. Uses a validated-get node.
In order to create a validated-get node, right-click an existing Get node and choose
`Convert to Validated Get`
